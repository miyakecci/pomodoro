# ポモドーロタイマー

React + TypeScript + Vite で作った静的Webアプリです。サーバー・DB不要で、S3 + CloudFront に置くだけで動きます。

## 機能
- 集中 / 休憩 / 長い休憩 の切り替え（既定 25分・5分・15分、4回ごとに長い休憩）
- 円形プログレス表示、タブのタイトルにも残り時間を表示
- 終了時のベル音（音声ファイル不要）とブラウザ通知
- 今日の集中回数の記録、時間設定・自動開始の保存（localStorage）
- ダークモード、スマホ対応

## ローカルで動かす
Node.js 20 以上が必要です。

    npm install
    npm run dev      # http://localhost:5173 で確認
    npm run build    # dist/ に本番用ファイルが出力される

## AWS へのデプロイ
1. 非公開の S3 バケットを作成
2. CloudFront ディストリビューションを作成（オリジン = S3、OAC を設定、デフォルトルートオブジェクト = index.html）
3. 独自ドメインを使う場合は ACM（us-east-1）で証明書を発行し、Route 53 でエイリアスレコードを作成
4. 以下でビルドとアップロード、キャッシュ削除をまとめて実行

        BUCKET=バケット名 DIST_ID=ディストリビューションID ./deploy.sh

`dist/` フォルダの中身を S3 コンソールから手動アップロードしても動作します。

## 主なファイル
- `src/App.tsx` … タイマーの動作と画面
- `src/index.css` … デザイン（色は先頭の変数で変更できます）
- `deploy.sh` … S3 へのデプロイスクリプト
